# Свои

Небольшой приватный веб-мессенджер для своей группы.

Сейчас реализовано:
- регистрация и вход;
- список пользователей;
- личные сообщения;
- хранение истории в SQLite;
- доставка новых сообщений в реальном времени через WebSocket;
- мобильный интерфейс.

Следующие этапы: групповые чаты, вложения, уведомления и WebRTC-звонки 1:1/до 10 участников.

## Запуск

```bash
python3 -m venv venv
./venv/bin/pip install -r requirements.txt
./venv/bin/uvicorn app:app --host 127.0.0.1 --port 8010
```

Данные сохраняются в `data/svoi.db`.
