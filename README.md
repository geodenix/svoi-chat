# Свои

Небольшой приватный веб-мессенджер для своей группы.

Сейчас реализовано:
- регистрация и вход по логину/паролю;
- запоминание входа на устройстве до явного выхода;
- список пользователей и онлайн-статус;
- личные и групповые чаты;
- фото и файлы до 20 МБ;
- статусы отправлено / доставлено / прочитано;
- история в SQLite;
- доставка новых сообщений через WebSocket;
- мобильный интерфейс.

Следующие этапы: уведомления и WebRTC-звонки 1:1/до 10 участников.

## Запуск

```bash
python3 -m venv venv
./venv/bin/pip install -r requirements.txt
./venv/bin/uvicorn app:app --host 127.0.0.1 --port 8010
```

Данные сохраняются в `data/svoi.db`.
