# Свои

Небольшой приватный веб-мессенджер для своей группы.

Сейчас реализовано:
- регистрация и вход по логину/паролю;
- запоминание входа на устройстве до явного выхода;
- список пользователей и онлайн-статус;
- личные и групповые чаты;
- фото и файлы до 20 МБ;
- статусы отправлено / доставлено / прочитано;
- история в SQLite;
- доставка новых сообщений через WebSocket;
- мобильный интерфейс.

Следующие этапы: уведомления и WebRTC-звонки 1:1/до 10 участников.

## Запуск

```bash
python3 -m venv venv
./venv/bin/pip install -r requirements.txt
./venv/bin/uvicorn app:app --host 127.0.0.1 --port 8010
```

Данные сохраняются в `data/svoi.db`.


## SMS-подтверждение номера

Привязка номера выполняется только после подтверждения 6-значным кодом из SMS.

На сервере используется SMS.RU. Секретный API-ключ не хранится в репозитории и не должен попадать в APK.

Добавьте в `/etc/svoi-chat.env`:

```env
SMS_RU_API_ID=ваш_api_id
# Необязательно: согласованное имя отправителя SMS.RU
# SMS_RU_FROM=Svoi
# Для тестового запроса без реальной отправки:
# SMS_RU_TEST=1
```

После изменения переменных окружения перезапустите сервис:

```bash
systemctl restart svoi-chat
```

Ограничения подтверждения:
- код: 6 цифр;
- срок действия: 10 минут;
- повторная отправка: не чаще одного раза в минуту;
- не более 10 SMS-кодов за 24 часа на аккаунт;
- не более 5 попыток ввода одного кода.

Неподтверждённые номера не участвуют в поиске совпадений телефонной книги.
